# ROM Clinic

Next.js application using TypeScript, App Router, Tailwind CSS, and ESLint.

## Requirements

Node.js 20.9 or newer and npm.

## Development

```sh
npm ci
npm run dev
```

Open http://localhost:3000. The homepage is in `src/app/page.tsx`.

## Checks and production

```sh
npm run lint
npm run build
npm start
```
